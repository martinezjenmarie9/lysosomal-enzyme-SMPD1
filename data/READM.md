## Project Overview
This project focuses on the SMPD1 gene, which encodes acid sphingomyelinase, a lysosomal enzyme involved in sphingolipid metabolism. The project uses a protein sequence downloaded from the NCBI Protein database and the R script provided for the lysosomal enzyme analysis activity.

## Tools and Resources
* NCBI Protein Database – Source of the SMPD1 protein sequence.
* RStudio – Environment used to run the provided R script.
* R – Programming language used for the analysis.
* rentrez – R package for accessing NCBI data.
* ggplot2 – R package for creating visualizations.

## Conclusion
This project documents the retrieval of the SMPD1 protein sequence from NCBI and the execution of the provided R script in RStudio. The resulting output provides the basis for examining the SMPD1 sequence in the context of the lysosomal enzyme analysis activity.
