## Project Overview

This folder contains visualizations generated by running the provided R script in RStudio. The figures summarize the amino acid composition and potential N-glycosylation motifs identified in the analyzed protein sequence.

## Tools and Resources
* NCBI Protein Database – Source of the SMPD1 protein sequence.
* RStudio – Environment used to run the provided R script.
* rentrez – R package for accessing NCBI data.
* ggplot2 – R package for creating visualizations.

## Conclusion

The figures provide a visual summary of the protein sequence analysis. Amino acid composition describes the sequence's residue distribution, while the motif plot highlights potential N-glycosylation sites for further investigation.
