# Exploring Lysosomal Enzymes Using NCBI and R

## NCBI Record 

**Gene Symbol:** SMPD1

**Gene Name:** Sphingomyelin phosphodiesterase 1

**Enzyme Name:** Acid sphingomyelinase

**NCBI Protein Accession:** NP_000534.3

**NCBI Protein Record Link:** https://www.ncbi.nlm.nih.gov/protein/NP_000534.3

**What It Breaks Down:** Sphingomyelin into ceramide and phosphocholine.

**Normal Function:** Breaks down sphingomyelin in lysosomes, supporting normal lipid metabolism and cell membrane maintenance.
